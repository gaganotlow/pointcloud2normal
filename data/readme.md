# 数据集索引

忘记数据集用途时，先看这里。详细的坐标、深度和字段说明在各数据集目录内。

## 先做选择


| 现在要做什么                   | 应使用的数据集                                                 | 不要使用                                       |
| ------------------------------ | -------------------------------------------------------------- | ---------------------------------------------- |
| 训练或评估当前的点云法向模型   | `msecnet_ball_v1_fuelcap_pass_20260803_10847_manual3d_r08`     | 伪 OBB 的无向指标不能拿来比较。                |
| 复现当前历史协议`msecnet_best` | `msecnet_best_fuelcap_pass_20260803_10847_manual3d_pseudo_obb` | 不要将其误差与球形模型的有向误差横比。         |
| 更改裁剪参数、重新制备训练集   | `fuelcap_pass_20260803_10847`                                  | 不要覆盖已有派生目录。                         |
| 检查模型在新车上的表现         | `msecnet_20260730_open_obb10_unlabeled_test`                   | 它没有标签，不能计算角度误差，也不能用于训练。 |

## 共同前提

- 所有 3D 坐标均在 **CV 相机坐标系**，单位为 **米**。
- 标签 JSON 的 `normal` 是盖中心的单个监督目标；点云 NPZ 的 `normal` 是逐点表面法向。这两个字段不能混用。
- `label == 1` 是 3D 内盖分割。当前两个训练集都不靠它或 `knob_obb` 取点。
- 切分必须按车型或采集组保持完整。不要按单帧随机切分，否则相邻帧会泄漏到验证或测试集。
- **互斥规则：** 当前训练、微调和 RGB 融合只能使用 `fuelcap_pass_20260803_10847` 及其两个派生集；9211 和更早版本只作历史存档。训练脚本会按 `dataset.json` 的 `source_dataset` 拒绝旧集或混合路径。

## 当前原始集：`fuelcap_pass_20260803_10847`

这是 2026-08-03 导出的最新审核通过、未标异常油箱内盖数据，共 10,847 帧、145 个 `car_model`，覆盖 9 个采集域。它是当前训练的唯一原始来源。

目录和字段语义与下方 9211 历史原始集相同；重制训练数据时从本目录的 `index.jsonl`、`clouds_full/` 与 `labels/` 读取。新版本新增了 `depth_full/` 和 `clouds_fullframe/`，但当前球形/伪 OBB 准备脚本仍只使用 `index.jsonl` 指向的 `clouds_full/` 和人工标签。

## 历史原始集：`fuelcap_pass_20260721_9211`

**它是什么：** 2026-07-21 导出的旧版油箱内盖审核通过、未标异常数据，共 9,211 帧、145 个 `car_model`，覆盖 9 个采集域。它仅用于追溯旧实验，不能作为当前训练来源。

**什么时候看它：** 需要重做裁剪、追溯单个训练样本、使用 RGB/深度，或检查人工标签时。


| 文件                    | 记住它是什么                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| `index.jsonl`           | 一帧一行的总索引，给出图像、全量云、局部云、标签及车型的相对路径。                               |
| `clouds_full/<帧>.npz`  | 原始全量点云。重制球形和伪 OBB 数据集都从这里取点。                                              |
| `clouds_local/<帧>.npz` | 已有的局部预裁云，主要用于浏览，不是当前训练集的裁剪来源。                                       |
| `labels/<帧>.json`      | 人工审核的中心`center`、目标法向 `normal`、切向量 `tangent`、位姿 `pose_T`、矩形尺寸 `disc_wh`。 |
| `cars.json`             | 车型到帧的映射，可作为新实验整组切分的依据。                                                     |

`scale` 恒为 1，应忽略。涉及深度尺度、相机轴向或双目左右相机时，必须先读当前源数据的 [坐标系与易错参数说明](fuelcap_pass_20260803_10847/坐标系与易错参数说明.md)。

## 当前集：8 cm 人工中心球

目录：`msecnet_ball_v1_fuelcap_pass_20260803_10847_manual3d_r08`


| 项目     | 含义                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| 目标     | 预测人工 3D 中心处、朝向相机的法向。                                                                                 |
| 输入     | 从原始全量云中取 `||point - center|| <= 0.08 m` 的球形邻域。                                                        |
| 标签     | 同一人工中心的`normal`；球内其他表面只是上下文。                                                                     |
| 规模     | 10,846 个样本；每个球至少 80 点，至多预采样 4,096 点。                                                               |
| 切分     | `split_by_generalization_group.json`：train 8,676 / val 1,085 / test 1,085。按车型或采集会话分组，避免近重复帧泄漏。 |
| 对应代码 | `msecnet_ball/train.py`、`msecnet_ball/infer.py`。                                                                   |
| 指标     | **有向** `angular_error_deg`：预测反向就是错误。                                                                     |

这是当前首选协议。它回答的是“这个人工指定的中心点，盖面法向朝哪里”，不是逐点法向或盖面分割。

## 历史集：人工伪 OBB 薄片

目录：`msecnet_best_fuelcap_pass_20260803_10847_manual3d_pseudo_obb`


| 项目     | 含义                                                                                        |
| -------- | ------------------------------------------------------------------------------------------- |
| 目标     | 复现历史`msecnet_best` 的训练/推理协议。                                                    |
| 输入     | 沿人工矩形平面截取薄长方体：面内尺寸为`disc_wh` 的 2 倍，半厚为 5 mm。                      |
| 标签     | 人工`normal`；人工矩形只用来选取输入点。                                                    |
| 规模     | 10,826 个样本；每片至少 80 点，至多预采样 4,096 点。                                        |
| 切分     | `split_by_car_model.json`：train 8,635 / val 1,103 / test 1,088。整个车型只属于一个 split。 |
| 对应代码 | `msecnet_best/train.py`、`msecnet_best/infer.py`。                                          |
| 指标     | **无向** `axis_error_deg`：`n` 与 `-n` 等价。                                               |

它是历史基线和消融对照，不是当前部署目标的首选数据集。伪 OBB 是由人工 3D 矩形构造的输入区域，不等于部署时检测器输出的 2D OBB。

## 开放集：检测器 OBB 裁剪

目录：`msecnet_20260730_open_obb10_unlabeled_test`

**它是什么：** 2026-07-30 五辆车外盖多角度数据的独立开放集，不来自当前 10847 原始集。对每张 RGB 图做 class 0 YOLO OBB 检测，将框的宽高扩大 10%，再把原始点云投影到图像并保留框内点。

**它能做什么：** 共有 42 个 `test` 样本，可运行 `predict_unlabeled.py` 或在 Web 中查看预测和聚合强度。

**它不能做什么：** 没有人工中心和人工法向，因此没有 `labels_manual3d.npz`，不能计算测试角度误差，不能参与训练或模型选型。球形模型在此处会将 OBB 裁剪的质心当作近似中心；这只是推理策略，不是人工标注。

## 派生训练集中的文件

球形集和伪 OBB 集都使用下列文件约定。


| 文件                    | 用途                                                                  |
| ----------------------- | --------------------------------------------------------------------- |
| `clouds/<帧>.npz`       | 训练输入点云，含`xyz`、占位 `label`、`K_norm`、`w`、`h`。             |
| `labels_manual3d.npz`   | 训练标签；`files` 对应云文件，`normal` 是目标，`n_inner` 是保留点数。 |
| `anchors_manual3d.json` | 人工中心、法向、矩形、位姿，以及这次裁剪采用的参数。                  |
| `manifest.jsonl`        | 每个派生样本回溯到原始云、标签、采集域、车型和 split 的记录。         |
| `split_*.json`          | 唯一有效的 train/val/test 划分。                                      |

`inlier_frac` 与 `agree_deg` 是为兼容历史读取接口保留的字段；当前人工标注数据中分别恒为 1 和 0。

## 改数据前

1. 仅从 `fuelcap_pass_20260803_10847` 制备新版本，并使用新的输出目录。
2. 保留本 README 里的几何、标签和指标边界，不要混用球形/伪 OBB/开放集结果。
3. 所有制备、训练与推理命令都在 `point2normal` Conda 环境运行。

各派生目录内的 README 是制备脚本写入的简短快照；本文件是数据集之间关系的总入口。
